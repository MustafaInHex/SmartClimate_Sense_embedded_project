# SmartClimate_Sense_embedded_project


# Description
An embedded C project for the ATmega32 microcontroller designed to measure and display both positive and negative temperatures using LM35 temprature sensor. 

# Components & Tools
*   **Microcontroller:** ATmega32
*   **Temperature Sensor:** LM35
*   **Display:** LCD 16x2, Seven Segment
*   **Simulation:** Proteus Design Suite
*   **Language:** Embedded C

## 📁 Project Structure
*   `/Src` - Contains all the main C source code files.
*   `/Inc` - Contains all the C header files.
*   `/Proteus` - Contains the Proteus simulation design files.

## 🔧 How to Run
1. Open the design file in the `Proteus` folder using Proteus Design Suite.
2. Compile the code in your IDE (e.g., Atmel Studio).
3. Load the generated `.hex` file into the ATmega32 in Proteus.
4. Run the simulation to observe temperature changes.
